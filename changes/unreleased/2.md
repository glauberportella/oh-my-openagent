**The GUI bridge skeleton lands as `packages/omo-gui-bridge`.** OmO's web GUI now has its shell-agnostic inner layer: a loopback-only HTTP+SSE server bound to 127.0.0.1 behind a one-time token gate, with an in-process event bus, monotonic SSE frames, and heartbeat keepalives — the foundation the OpenCode and Senpi attach clients and the SPA publish onto in both browser and Electron deployments.
